## 🚀 Featured projects

### 🤖 KEEL — multi-agent AI drift detection
A multi-agent system that detects **semantic drift** between a human's intent and an AI's output. A **C++ coordinator** fans requests out to a set of specialized agents, aggregates their judgments into a single drift assessment, and streams the results to a real-time dashboard. Async, fire-and-forget loggers (spdlog) handle thread-safe observability.

> 🏆 **Top 50** at the lablab.ai *Band of Agents* hackathon — 2 perfect & 2 near-perfect judge scores.
>
> 👥 Built with a teammate: I architected the C++ coordinator (orchestration + concurrency) and built the frontend with AI assistance; my teammate built the agents and helped connect the frontend to the coordinator.

`C++` · `Intel TBB` · `spdlog`

### ⚡ GrindCoders
A high-performance, full-stack competitive-coding platform built solo in ~2 months. Go/Gin backend tuned for low memory overhead, with a strongly-typed, animated Next.js frontend.

`Go (Gin)` · `Next.js / TypeScript` · `Framer Motion`

### 📱 Quranify
A cross-platform (**Android + Web**) Quran app shipped from a single Flutter/Dart codebase, using an AI-assisted workflow for fast UI/UX iteration.

`Flutter` · `Dart`

### 🏎️ MarioKart
